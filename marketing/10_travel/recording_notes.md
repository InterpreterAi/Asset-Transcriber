# Recording notes — 10 Travel

## Who speaks first
**Airline agent (English)** with missed connection + rebook offer.

## Pace & pauses
- Flight number: “two-six-four”.
- Times: “seven-forty p.m.” / “six-ten” — pause slightly between digits groups.
- Passenger chooses hotel option clearly; agent confirmation is the close.

## Overlaps
None. Airport noise optional in room tone only — keep dialogue clean for STT.

## When the demo should shine
1. **missed the connection / Chicago / flight two-six-four / seven-forty p.m.**
2. **standby / waitlist / hotel voucher**.
3. **lodging voucher / meal coupons / gate information**.

## Camera / UI tips
Good vertical reel: agent offer → passenger chooses confirmed AM → voucher confirmation → outro. Show usage chip “Xm / 2h” if you want trial framing in the same cut.
